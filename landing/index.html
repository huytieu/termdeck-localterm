The terminal

Every tab is a shell.

The full localterm session model — open a tab to spawn a shell, close it and it waits in the switcher, never reaped mid-command. TermDeck adds the signals you need to run a fleet of agents.

Status at a glance

Know who needs you

A minimal colored glyph per session, so a screen full of agents tells you where to look.

● running ● needs you ○ idle · done

Hover to kill

Stop a session in place

A small ✕ appears on each row — end a run from the list without opening the grid.

Usage quota

Limits in the header

Session and weekly bars with % remaining and reset countdown, right where you work.

s:▰▰▱▱▱ 52% ↻2h w:▰▰▰▰▱ 94% ↻6d

The wiki

A home for your Markdown.

The notes your shells live next to, made legible. Browse the vault, read it like a document, and edit it like Notion — without leaving the tab.

Read

A calm reading surface

Serif type, a centered measure, coral accents, and a Properties / Location / Stats panel with live word count and reading time. Reading mode hides all the chrome.

Write

WYSIWYG that keeps your Markdown

Headings, lists, tasks, tables, code — edited as rich blocks with a faithful round-trip. Frontmatter and [[wikilinks]] stay intact. Flip to raw source anytime.

Organize

A file tree that remembers

Persistent expand/collapse, extension filters, full-text search, one-click new note (defaults to .md), inline color swatches, and syntax-highlighted code.

Quickstart

Running in a minute.

Clone, build, and start the daemon. Loopback needs zero setup; a tailnet gives you every device.

# clone & build
git clone https://github.com/huytieu/termdeck-localterm
cd termdeck-localterm
pnpm install
pnpm build

# boot the daemon, then open the URL it prints
pnpm start
pnpm cli status   # → http://localterm.localhost:3417
